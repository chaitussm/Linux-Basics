# Exercise 01 — Navigation & file system

**Goals:** `pwd`, `cd`, `ls`, `mkdir`, understand `/` hierarchy.

1. Run `pwd` and `cd` to `/tmp`, then back to your home with `cd ~`.
2. List all files including hidden: `ls -la`.
3. Create `practice/nav-demo` with `mkdir -p`.
4. Read `docs/linuxBasics.md` section 3 and name five directories under `/`.

**Check:** You can explain what `/home`, `/etc`, and `/proc` are used for.
