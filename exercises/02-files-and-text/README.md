# Exercise 02 — Files, sort, uniq, wc

**Goals:** `touch`, `cat`, `head`, `tail`, `sort`, `uniq`, `wc`.

1. Copy `sample/names.txt` and sort it: `sort names.txt`.
2. Run `sort names.txt | uniq -c` to count duplicate lines.
3. Run `wc -l words.txt` on `sample/words.txt`.
4. Append a line with `>>` and view with `tail -3`.

**Check:** Difference between `sort -u` and `uniq` on unsorted input.
